## 已有代码能力

生产 Web 快照包含：

- 一个统一工作台管理多个租户/公司站点，Payload Multi-Tenant 插件及 collection access 共同参与隔离。
- 产品、新闻、案例、分类、关于我们、FAQ、联系方式、首页、导航、媒体、询盘等管理入口和对应站点渲染路径。
- 多语言字段和翻译操作；产品有后台批量翻译任务与独立 Worker。翻译结果应由运营人员复核。
- 联系/报价表单向租户询盘集合写入，含站点和来源上下文。
- 模板演示和客户站点渲染代码。V1 优先目标是古建、配电柜和紧固件；注册表中仍含历史模板或演示模板。

这些条目描述源码具备的实现，不代表完整验收。历史执行/验收材料可在 `docs/admin-redesign`、`docs/template-upgrade`、`docs/v1` 查阅；它们是在各自日期范围内形成的记录，应结合本文阅读。

## V1 产品范围与未完成项

- **后台定位：** V1 供内部运营团队使用的统一后台；后续可规划客户独立权限后台。
- **正式域名：** V1 要求支持客户自己的正式域名；当前自动绑定、DNS/证书流程和客户站点路由尚未完整交付。
- **管理域预览询盘：** 需要支持受控的真实测试询盘，持久化入库并明确标记为测试；这项功能尚待开发。当前不应把正式客户数据用于界面验收。
- **验收：** V1 尚未声明整体完成。模板视觉接受、全部浏览器矩阵、迁移/恢复演练和实际域名接入需以负责人单独验收记录为准。
- **开源安全：** 当前候选已增加 seed 生产环境禁用、非生产显式启用及平台超级管理员授权检查，并移除固定演示口令。此安全修订未部署，线上仍运行原 Web 基线。
- **素材：** 模板演示素材应与客户上传媒体隔离。Pexels 来源/许可信息记在对应 manifest；素材不能解释为客户项目成果、认证或自有产品照片。
- **公开演示数据：** 当前候选的演示模板与 PDF 使用 `.invalid` 保留域名、虚构号码和 NovaSite 演示标识。第三方图片来源分别记录在素材 manifest；许可和再分发边界见 `THIRD_PARTY_NOTICES.md`。
- **历史 Git 对象：** 原公开仓库的旧提交包含机器绝对路径、旧截图和 Payload 官方演示账号/密码说明（不是生产凭据）；当前候选树已去掉旧本地路径、截图、固定演示凭据说明和临时 `test.env`，但保留 Git 历史意味着这些旧对象仍可从历史查看。本阶段没有重写历史；若政策要求历史里也完全没有这些内容，需要另行审查历史清理方案。
- **静态扫描范围：** 环境没有安装 `gitleaks` CLI；本轮使用仅输出文件路径和类别、不输出命中值的本地规则扫描，并结合人工审查。它不能替代正式安全审计。旧 `.env.example` 和 Compose 中的本地开发连接字符串/口令属于公开开发示例，不是生产凭据；仍应确保其不会被复用到生产。
