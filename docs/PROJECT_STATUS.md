# 当前项目状态

更新：2026-10-30，源码版本 v1.3.0。

## 当前范围

多公司网站内容、语言、媒体、询盘、模板演示与选择、统计、GEO 素材、知识库、文章创作与发布。新增 K607、K712、AllyNav 模板，演示与客户网站共用对应模板组件，数据来源独立。

## 本轮检查

- 生产 Web 构建与运行源码类型检查通过。
- 模板隔离、域名路由、预览询盘、知识库设置、GEO 检测边界和媒体分块相关的 9 个测试文件、61 项断言通过。
- AllyNav 的 27 条支持示例路由和未知详情拒绝检查通过。
- 这些检查不替代用户对所有模板、页面、动画和编辑流程的验收。

## 发布与数据边界

GitHub 同步与服务器部署分别记录在 [v1.3.0 发布记录](RELEASES/v1.3.0.md)。当前为发布准备，不能把源码同步当作服务器已更新。

本轮不导入本地客户数据库或上传，不使用 seed，不切换任何现有公司的模板。GEO 检测目前仅支持本地存储验收，生产环境继续关闭该入口；本次不为它自动执行数据库结构迁移。

## 验收边界

- 当前为待用户验收。
- AllyNav 使用有限示例素材，演示表单仅在浏览器本地保存，外部视频依赖网络。
- 用户可配置的现有内容和模板功能仍由现有后台提供。未建立的源站专有数据模型不以第三方示例冒充客户内容。
- 历史版本对应、规划与实施材料按各自日期理解；入口见 [文档导航](README.md)。
