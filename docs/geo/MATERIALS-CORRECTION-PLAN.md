日期：2026-10-17。用户要求暂停第7步，先核对参考站素材库，再说明修改方案。本轮仅调查与方案，不改3100代码或数据库。

## 先改哪些内容

### 1. 素材页恢复目录加内容区

沿用3100现有客户后台外框与GEO导航；只重做素材库工作区。左侧显示目录及素材组，右侧显示所选组的图片与数量，右上提供“上传素材”。去掉现有作为主入口的素材组表格及“从当前客户媒体库添加”。

外层目录和实际素材组按参考站层级呈现。保留已有素材组ID及原任务引用，不能通过删除重建旧组来达到界面一致。

### 2. 创建采用弹窗

恢复参考站的小弹窗及名称计数，不再把“创建一个组”变成填写大段说明的独立配置页。名称、位置和层级必须清楚，空组有可理解的提示。

### 3. 在组内直接上传电脑图片

点击上传后打开抽屉，显示当前保存位置，直接选择电脑图片，可一次多选。上传过程逐张显示处理、成功或失败；失败保留可重试项。成功图片立即出现在选定组中，数量来自保存结果。

用户只需完成“选组 → 上传 → 选电脑图片”，不跳转到另一套媒体管理页面，不要求先去其他模块上传再回来选。

先落实文章所需图片上传。参考站是综合素材系统，本轮不顺带接视频、音乐、剪辑或完整标签系统，也不照抄尚未验证的1GB提示。格式/大小提示必须与本项目真实服务端能力一致；当前文章链路只接受JPG/PNG/WebP、单图500KiB，因此上传实现需要与现有创作/发布校验配套，不得仅放开前端选择后让后续文章失败。

### 4. 沿用现有客户与任务约束

上传目标客户及素材组由服务端登录上下文核对；切换客户取消旧页面请求，不能将旧选择带到新客户。文件上传成功与入组成功分别处理，失败不能显示虚假成功、不能把重复请求变成多张重复图片。

保持现有文章任务只选择素材组的规则，不新增另一种素材配置方式。旧客户文件、素材组及已有任务不会为本次UI修正被批量迁移或删除。

## 暂不扩展

第7步发布计划暂停。不新增媒体管理入口、知识库、视频/音乐处理、剪辑、复杂标签、批量管理等额外功能。先交付与参考站使用路径一致的分组浏览、创建和电脑图片上传。

## 已知检查边界

本轮对参考站实际页面进行只读交互及获准的临时空组创建，对照3100现有GeoMaterials组件和上传接口源码；没有打开3100做逐像素截图比对，没有实际文件上传，也没有宣称上传闭环已经通过。

下一轮修改涉及的主要位置：GeoMaterials页面及样式、当前客户素材组数据接口、组内上传处理；若层级适配确需增量结构，先列清具体方案并保留已有组ID，不把现有客户内容当测试数据。
