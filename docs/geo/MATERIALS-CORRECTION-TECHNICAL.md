# GEO素材库修正技术文档

状态：3100本地界面已按参考站完成本轮对照修正；GEO增量结构此前已在本机应用。2026-10-18再次对照江西中品测试站的素材组、创建弹窗和上传抽屉。

日期：2026-10-17；对照修正：2026-10-18

## 范围与结果

本轮按用户确认，只对齐素材组和电脑图片上传，不增加标签、素材筛选、移动或批量删除。知识库、视频/音频、图片编辑和媒体库选择器均不在本次范围内。素材库仍以“素材组”为文章创作配置单位。

界面采用左侧分组树、右侧内容区。点击“创建”只创建素材组，弹窗标题“创建素材组”，名称限制为1—15个字符；选择素材组后可从右上“上传素材”打开右侧抽屉并直接选择电脑文件。已有目录层级和素材组ID保留，文章任务中的素材选择仍只返回素材组。上传抽屉显示当前保存位置和文件列表，文件成功后立即进入当前组。

页面继续使用3100管理后台的客户工作区框架和GEO导航，没有新增独立媒体管理入口。电脑图片会通过现有 Payload `media` 文件存储创建客户归属记录，再由服务端立即加入当前 GEO 素材组；用户流程中不再出现“先去媒体库上传，再从媒体库挑选”。

## 页面行为

- 创建素材组弹窗：标题、输入框和15字计数与参考站一致；不额外显示“保存位置”说明，归属仍由当前分组上下文决定。
- 图片区：显示当前组内图片和数量。没有图片时提供直接上传入口；不要求先保存到另一个媒体页面。
- 上传抽屉：支持从电脑多选图片，显示保存位置、文件名和大小。全部文件成功时关闭；部分失败时保留失败项供重试。文件仍经客户媒体存储保存，但界面没有媒体库挑选步骤。
- 页面不显示图片类型/标签筛选、移动、批量管理或归档操作；既有归档记录及所有历史任务数据保持原状。

## 电脑图片上传与安全

接口：`POST /api/workspace/{company}/geo/materials/{groupId}/upload`，使用 `multipart/form-data`，字段为 `version` 和多个 `files`。

- 允许 JPEG、PNG、WebP；单张最大500KB；每批最多20张；每组最多200张。限制与当前 GEO 文章生成链路一致。
- 服务端重新校验扩展名、MIME、大小、组版本、归档状态、组容量和媒体客户归属；浏览器校验只用于提前给出提示。
- 上传需要当前客户的素材编辑权限。文件记录写入当前 `tenant_id`，通过现有媒体租户授权创建，素材关联和组版本更新在数据库事务中完成。
- 组版本竞争时最多重读并重试三次；无法确认加入时返回失败，不显示成功状态。多租户条件贯穿素材组查询、媒体查询、父目录外键和数据库触发器。
- 复用客户媒体存储作为文件和文章图片 ID 的底层载体，不提供媒体库选择界面。

## 旧任务兼容

文章任务保存的是当时的图片 ID 快照。本次没有改写这些任务或图片关联。素材组新增图片会更新组版本，但旧任务继续使用自己的快照；生成前仍检查快照图片是否仍属于当前客户的原素材组、图片类型和大小是否有效。发布时也按快照图片 ID 检查组内关联。移出图片、归档组或客户归属不匹配仍会阻止继续使用。

编辑旧任务时，如果它引用的素材组版本落后，现有任务界面仍会提示采用当前版本；用户确认更新任务时才读取新组版本。
