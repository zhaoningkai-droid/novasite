# v1.3.1 · GEO 正文格式恢复

来源核查模式的正文遇到非标准 JSON 时，旧逻辑直接失败；关键词模式已有一次格式修复。现在两种模式共用一次受限格式修复，并直接识别完整 JSON 代码围栏，后者无需额外模型请求。引用和原文证据继续严格验证，截断响应、服务失败仍不自动重试。修复请求的用量累加记录，不把格式损坏内容保存成成功文章。

新增回归场景来自生产 INVALID_OUTPUT 故障：围栏 JSON、来源模式格式修复、修复后伪造引用拒绝、修复次数上限及截断拒绝。与审核、发布、计划和接口检查共 6 组、73 项测试通过。测试使用注入响应，不调用真实模型。

包含一个现有单机 Web 镜像切换工具：校验配对备份、冻结写入、比对业务表完整行摘要、健康检查失败回退应用配置；不迁移、seed 或恢复客户数据。生产配置和审计输出不进入仓库。

2026-10-31 已部署 GEO Article Worker `novasite-tools:v1.3.1-geo-json`；Web 保持已验证的 v1.3.0。修复仅涉及生成进程，未修改已有文章、任务源资料或发布状态。当前为待用户验收。
