# 官方视频上传修复

日期：2026-10-20。

用户报告约50MB视频无法上传。页面此前提示512MB，但Next.js代理仍按默认10MB缓冲，导致媒体路由拿不到完整的multipart文件；边缘入口另外限制为256MB。已在旧版页面用52.22MiB有效MP4实际复现失败，日志出现超过10MB警告。

按用户最新要求，将视频文件上限统一为256MiB：前端提示和校验、媒体API文件校验一致；Next.js缓冲和Caddy媒体上传入口允许257MiB请求，为multipart字段留出1MiB。其他Caddy路由仍保持原来的256MB限制，图片500KB和PDF10MB不变。HTTP413返回时使用中文容量提示。权限、公司隔离、Caddy内存/超时及私有凭据配置保留。

无数据库迁移或客户内容导入。生产构建、相关ESLint及Caddy配置校验通过；部署后的实际上传结果另行记录。
