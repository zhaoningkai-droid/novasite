# 网站数据自动更新与实时访问

日期：2026-10-20。

网站数据页改为每分钟自动读取最新数据。页面隐藏、离线或正在更新时暂停请求，重新回到页面或恢复网络后补查；切换公司和离开页面会清理旧定时器。保留手动刷新入口，标准报表缓存由两分钟改为一分钟。

新增当前公司近30分钟的实时浏览量。Google标准报表与实时接口使用不同的数据处理链路：标准报表尚为空时，不能用实时计数冒充累计或趋势。页面移除“测试资源”和“GA4测试”标识，明确显示标准报表尚待处理的状态。

Google实时API不支持hostname/pagePath筛选，因此使用公司、来源域和路径范围共同派生的独立浏览事件，仅为通过原有主机/页面校验并允许统计的访问发送。每次标准page_view对应一次实时事件，原PV报表仍只统计标准page_view，不会将两者相加。无需注册自定义维度或扩大Google权限。实时失败显示不可用，不伪装成零；不同客户即使误配同一媒体资源，也不共用实时查询结果。

不涉及数据库迁移、客户内容导入、模板调整或凭据提交。服务器继续使用现有私有配置及只读凭据挂载。

验证：5个相关测试文件20项通过，覆盖定时更新、后台暂停、请求清理、实时缓存、失败/零值区分、客户隔离和采集去重。TypeScript、相关ESLint及生产构建结果记录在本次本地执行证据中。

参考：[Google数据处理延迟](https://developers.google.com/analytics/devguides/collection/ga4/troubleshoot)、[实时API支持的维度和指标](https://developers.google.com/analytics/devguides/reporting/data/v1/realtime-api-schema)。

真实Google接口进一步验证：eventName筛选与activeUsers指标不兼容，实时区域因此仅展示按公司隔离的浏览量，不查询整个资源的用户数来凑数。用户数继续使用下方标准报表。
