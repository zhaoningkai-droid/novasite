# NovaSite v1.2.0

发布日期：2026-10-19

本版本在现有多客户独立站后台加入GEO优化模块，源码发布不等于生产部署。

## 更新

- 按客户隔离优化词、素材组、文章任务、文章修订、发布计划和发布记录。
- 优化词支持品牌词、比对标识、核心词及细分词；官网和Blog地址作为发文链接。
- 素材组直接从电脑上传，取消组内图片总数量上限。
- 搜索问题生成、细分词全选、翻译前后切换、创作方向及文章数量弹窗。
- 本站新闻和Blog手动发布与按天自动计划；发布记录展示排期、执行及成功/失败结果。
- 成功记录查看改为右侧文章抽屉，展示发布正文快照和实际发布链接，支持复制。
- 客户工作后台取消未保存导航拦截，统一两秒错误提示。
- 包含GA4可选接入及相关后台调整，默认关闭。

## 验证

- GEO及全局提示24个集成测试文件，184项通过。
- TypeScript静态检查通过。
- Gitleaks扫描待发布源码，未发现密钥。
- 本地测试客户完成完整文章的新闻与Blog实际发布、成功记录回读、正文抽屉展示。

本次未运行全仓端到端测试或生产构建，也没有部署公网或验证AI搜索收录。

## 安装与升级

沿用项目已有依赖及本地/自托管运行说明。GEO需要专用数据库表、文章生成进程和发布进程；请先备份目标数据库，再按`docs/geo/`分步方案核对相应安装脚本。不要对已有客户库运行演示seed或未经核对的整批迁移。

AI与GA4凭证、实际环境文件、客户媒体、数据库备份、运行日志及本地截图证据均不包含在本次源码版本中。外部社交平台发布不属于本版本范围。
