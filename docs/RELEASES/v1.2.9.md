# v1.2.9 · 企业知识库与创作记录

创作记录采用紧凑表格，长问题与标题分两行显示，保留任务筛选、来源和发布状态；“查看”在右侧抽屉展示完整文章、图片、复制和字数，知识库引用资料单独展开查看。

新增企业知识库入口，支持 DOCX、TXT、MD、XLSX、CSV 上传、解析、分段、编辑、停用、归档和恢复。文档按公司隔离，原文件及版本保留；相同文件按公司去重。生成文章时检索当前公司的有效资料，结合中文检索、全文排序、融合排序及上下文扩展保存引用依据，并使用完整的十类创作模板。没有知识库时仍可按模板生成文章。

数据库仅新增 `platform_knowledge` 下的 bases、documents、chunks 三张表和索引，不导入本地客户数据，不替换线上已有数据或媒体。应用回退时保留知识库数据。

验证：63 项定向测试、12 项真实 PostgreSQL 数据隔离与版本检查、TypeScript 检查以及生产构建通过。部署需同时更新网页和文章生成进程，并执行 `20261022_010000_enterprise_knowledge` 迁移。

状态：待用户验收。
