# v1.3.0 · 当前平台与三套模板整合

整合本地 3100 项目的当前应用源码，包括 K607、K712 与 AllyNav 的独立演示、共用客户模板、现有内容编辑接入，以及 GEO 检测存储界面。

保留已发布的种子数据执行保护和现有客户资料。发布包不包含本地数据库、客户上传、运行密钥、历史截图或缓存。模板目录注册仅新增缺失的目录项，不替客户选择模板。

上线状态和实际校验结果在部署完成后另行补充，当前为发布准备。
