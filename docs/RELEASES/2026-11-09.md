# 2026-11-09 后台、翻译与 GEO 稳定性

- 后台列表减少重复请求。GEO 发布在临时权限查询失败时保留原计划状态。
- 独立站翻译任务在后台执行，切换页面后可继续查看进度。AI 翻译助手按当前公司和账号保留预览 7 天。移除平台设置的翻译用量上限，继续记录调用用量。
- GEO 生成前核对优化词与素材版本，生成记录显示队列状态和可重试的失败。状态不明的模型调用需人工确认。
- GEO 生成保存长段落和换行，接受常见正文字段，跳过空小节。整篇没有可用正文时给出明确提示。
- Web 编辑接口和编辑器可保存超长正文。该项已进入源码，线上 Web 待单独发布。

生产已切换后台、翻译和 GEO 生成服务。六条兼容迁移完成后核对客户、产品和媒体记录数量，随后验证后台登录与服务健康。GEO 正文热修单独更新了生成进程，线上复验批次的四条失败记录重试后全部生成并进入审核。

局部修复先复现失败样本，在 Git 中记录改动和测试结果。上线时切换受影响的服务，保留可回退的镜像和配置。涉及数据结构时，先在隔离副本演练迁移并验证备份。发布与回退步骤见 [部署、备份与回退](../DEPLOYMENT_AND_ROLLBACK.md)。
