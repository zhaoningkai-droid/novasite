# 大视频分段上传

日期：2026-10-20。

256MiB应用和源站容量对齐后，52.22MiB MP4已在真实后台上传成功且可读取22秒视频元数据；用户进一步报告190MB仍被入口拒绝。管理域流量经过Cloudflare，单个完整大请求仍可能受CDN请求容量限制。

超过64MiB的官方视频改为32MiB分段顺序上传，沿用原媒体接口的登录、角色、公司上下文检查。每段绑定上传ID、总大小、序号、文件名和类型，临时文件按公司及用户隔离；只在全部分段核对通过后合并并保存媒体，返回最终媒体ID。合并在磁盘进行，避免同时持有全部分段和完整视频；保存后清理临时文件，旧的未完成分段在后续上传时清理。最终文件上限仍为256MiB。

不修改Cloudflare/DNS/TLS防护，不新增数据库表，不自动把上传的视频发布到客户首页。4项定向测试覆盖分段合并字节一致、客户/用户隔离、最终处理锁、元数据篡改、容量/路径校验及前端顺序和进度。TypeScript及相关ESLint通过。生产构建通过，待190MB浏览器验证。

实际诊断补充：以有效约190MB视频发起完整请求，得到HTTP413及server: cloudflare响应，确认被前置CDN拒绝；浏览器完整请求另出现502，源站没有重启或OOM。分段请求避免跨越这一入口容量。
