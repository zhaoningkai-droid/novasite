# 多客户独立站运营后台：完整实施方案

版本：2026-09-07。依据：用户九张参考截图、完整实施方案、6批次30步执行计划。
当前授权：归档方案并执行第1步；后续逐步验收。以用户最新明确指令为准。

## 1. 目标和边界

一个后台管理多个客户，每个公司对应一个客户网站；登录先选公司，进入后可随时切换。产品、新闻、案例、博客、分类、页面、首页设置、媒体、导航、联系信息和询盘必须按公司隔离。

在已验收的 platform-v1（Next.js / Payload / PostgreSQL / 官方多租户插件）上重建日常运营界面，复用账号、数据库和媒体系统。上级目录的旧JSON后台不继续扩展。原生Payload后台作为维护入口保留；九个运营页面的常规编辑在新工作台内完成。

客户站继续采用现有VoltTrans基础模板、紧固件五金内容；不新增模板设计。参考公司的Logo、名称和草坪文案不复制到本系统。复用原有四语言内容结构；导航及产品参数已有按语言记录的兼容方案，不为界面重复创建四套集合。

允许占位：顶部除独立站外的预留模块、明确标注的模拟流量看板。其余业务按钮需要真实保存和可核验结果。此次不执行公网部署、正式生产迁移、机器自动翻译和其他营销模块。

## 2. 公司选择与入口衔接

现有入口：站点列表“进入工作台”调用官方多租户选择，随后跳转 `/admin/collections/pages`。复用这些客户数据和权限，新增选择公司页，而非另建客户数据库。

拟定路由（尚未实现）：
- `/workspace/companies`：登录后选择公司，按权限列出公司，支持搜索和进入管理。
- `/workspace/[company]/website/analytics`：当前公司网站数据。
- 同级子路由：`homepage`、`categories`、`content`、`about`、`faqs`、`contact`、`navigation`、`sites`。

登录成功先选择公司；进入后刷新保留上下文，未选择时不能直接编辑内容。右上角显示当前公司，切换后重新加载对应数据。无权公司的网址由服务端拒绝。编辑未保存时可保存、放弃或取消切换；切换产品编辑页时返回新公司的产品列表；清空旧勾选、旧弹窗和不适用筛选，防止旧请求晚返回覆盖新公司界面。

多标签页以页面URL中的公司为明确上下文，不能让全局cookie变化使旧页误写新公司。每次读取、保存、批量操作、图片和关联选择均由服务端验证用户权限和记录归属。用户操作调用Payload Local API时显式执行权限校验，不能默认绕过权限。

## 4. 视觉规范

九图是布局、字段、颜色的参照；原图归档在 `references/`。红色标注框不进入界面。自己的品牌占据截图Logo位置。顶部黑色，白色选中项和底部短线；侧栏白色、选中浅蓝底/蓝字/右侧蓝竖条；内容浅灰背景、白面板；浅灰表头、细分隔线；蓝主按钮、白描边次按钮、绿开关；标签页蓝字蓝下划线。

顶部顺序：首页、社媒营销、独立站、GEO优化、广告投放、客户管理、客户挖掘、自动化营销、企业知识库。独立站外点击显示“功能开发中”并保留公司。右侧铃铛打开“暂无通知”，不虚构通知；头像和公司下拉。

侧栏固定：网站数据；网站配置（首页管理、分类管理、内容管理、关于我们、常见问题、联系我们、网站导航）；站点管理。

使用同视口对照顶部高度、侧栏比例、间距、表格行高。长文省略可查看完整内容；小窗口不遮挡按钮。操作标签、提示、错误全部简体中文；编辑目标语言内容可正常显示外文，WhatsApp等品牌名保留。首页Banner标为轮播图，结构不变。无参考截图的公司选择页沿用相同表格/按钮规范，不额外创新大面积装饰。

## 5. 网站数据（图1）

顶部全部数据下拉筛选当前公司语言；刷新及近7天/30天/一年。四卡：总PV、UV、PV、询盘量，显示较上期变化。总PV为累计，PV/UV/询盘量为当前范围；比较前一等长范围，上期零显示暂无对比。下方PV/UV折线和来源分布环图，提供图例/悬停/空状态。

本次固定可重复模拟数据，范围切换同步改变所有图表，明确“演示数据，尚未接入真实流量统计”，不将模拟询盘当真实数据。分享按钮导出当前图表图片，不公开后台。

## 6. 首页管理（图2）

左侧八项固定顺序：1轮播图、2官方视频、3推荐产品、4推荐案例、5推荐新闻、6关于我们、7企业实力、8询盘表单。右侧对应编辑，独立保存与显示开关。

轮播三标签：电脑端、移动端、导航横幅。每项图片（上传或公司媒体库）、名称、简介、排序、跳转（站内/站外，栏目/内容类型/具体目标）。站内仅选择本公司内容。电脑/手机读各自配置；手机未配回退电脑图；多图轮播；导航横幅用于内页顶部。保持旧首屏兼容。

| 模块 | 编辑项 | 前台结果 |
| --- | --- | --- |
| 官方视频 | 标题、说明、封面、地址、开关 | 本公司视频 |
| 推荐产品/案例/新闻 | 选择、顺序、标题、开关 | 本公司符合发布条件的内容，顺序一致 |
| 关于我们 | 标题、简介、图片、跳转、开关 | 首页企业介绍 |
| 企业实力 | 数字、单位、说明、顺序、开关 | 数字不写死 |
| 询盘表单 | 标题、说明、开关 | 现有字段表单提交到本公司询盘 |

内容推荐开关和首页推荐选择共用关系，避免两份设置冲突。验证空列表、草稿、关闭模块和询盘归属。

## 7. 分类管理（图3）

四标签产品/文章/案例/博客分类；文章映射现有新闻，不复制集合。列：名称、级别、产品数量（其他标签对应内容数量）、排序、更新时间、翻译状态、操作（添加二级/编辑/删除），右上翻译/新增。

支持一级/二级、名称说明排序和四语种；不超过两级，不循环或跨公司关联。有内容/子分类阻止直接删除并提示处理，不连带删产品。数量来自真实公司记录，明确是否含子分类。博客现有树结构保留兼容。

## 8. 内容管理（图4）

四标签产品/文章/案例/博客。顶部名称搜索、分类、推荐筛选、批量删除/翻译/新增。列：图片、名称、分类、推荐开关、排序、翻译进度、更新时间、编辑/删除；分页清晰。

产品保留型号、摘要、正文、图片、技术参数、规格书、SEO和四语种；参数整合进产品编辑。新闻/案例/博客保留正文及原字段。分类、媒体和关联只选当前公司。搜索筛选真实查库；推荐/排序影响前台；删除只作用所选公司记录；保存失败中文提示并保留输入；选中跨页规则明确。

第12步的产品完整编辑页须严格补齐以下已确认差距，不提前用临时页面替代：统一前后台产品图片读取为 `gallery`；新增关键词、可新增产品标签和产品排序；图片必填、最多5张、推荐800×800且不超过500KB；产品详情富文本支持字号、颜色、对齐、列表和表格；右上提供 AI生成、继续添加、保存。验收提供从选择分类到保存成功的连续真实操作截图。

## 9. 关于我们（图5）

企业简介标签及图片/模块名称/描述/翻译状态表格，右上翻译/编辑。编辑支持多模块增改、图片、排序、移除。兼容原简介及资质，不能以空模块覆盖旧数据；前台按顺序显示，保留证书/实力能力。

## 10. 常见问题（图6）

序号、问题、答案、翻译状态、操作；翻译/添加。支持四语种、排序和长答案全文。前台读取本公司真实FAQ，首页/FAQ入口一致；FAQ结构化数据与实际展示一致，处理空列表。

## 11. 联系我们（图7）

地址（地图选择）、邮箱、电话、WhatsApp，右上保存。拟按图前三者必填、WhatsApp选填，兼容已有不完整记录。三个独立二维码位：WhatsApp/WeChat/微信；虽然后两者同品牌，但按参考保存为独立位，不合并覆盖原二维码。

地图选点保存坐标，地址可手填；服务加载失败仍可编辑。实施前核实地图服务条件，不默认有付费账号。保存后联系页、页脚、联系按钮读取同一来源；二维码从当前公司媒体库复用。

## 12. 网站导航（图8）

排序、目录名称、类型、更新时间、翻译状态、编辑/删除；翻译/添加。默认栏目、自定义站内外链接、二级菜单。使用稳定菜单标识关联现有四语言导航文档；界面一菜单一行而非一语言一入口。删除菜单不删除内容。页脚链接在导航编辑单独区域维护，不新增侧栏一级入口。

## 13. 站点管理（图9）

网站信息/博客信息标签。顶部域名、当前模板、添加时间、语言数量、站点设置。列表语言、域名/访问地址、状态、发布/更新时间、启停、配置/详情，带搜索和状态筛选。

本地只能标本地预览，未绑定域名给真实预览URL，无发布时间为“—”。语言停用必须影响直接访问、切换入口、sitemap/hreflang，至少保留一个启用语言；默认语言变更有一致规则。博客信息管理同公司博客栏目和语言访问，不另建数据库。设置复用名称/Logo/favicon/SEO/联系信息，不产生第二套。

## 14. 翻译定义

本次为真实四语种编辑/补全：查看缺失、修改保存、计算完成语言数。禁用fallback检查，不能把英文兜底误判俄语已完成；不覆盖未编辑语言。没有自动翻译服务时不假装机器翻译完成。自动翻译后续独立接入。

## 15. 技术组织和数据兼容

- 工作台路由与公共布局；公共表格/表单/媒体/翻译组件。
- 公司权限与上下文单独封装；业务服务负责首页、内容、分类、导航、语言状态。
- 复用现有collections和前台读取，增量字段有正式迁移和旧数据兼容。
- 预计补齐三端轮播、简介模块、实力数字、分类父级/排序、内容推荐/排序、第三二维码/坐标、稳定导航标识、语言状态。
- 实施前提交字段清单及风险；保留现有客户、四语言、媒体、历史正文/参数。现有脏工作区改动不清理、不覆盖。
- 准备独立测试数据库演练，生产迁移仍为上线待办；不对当前开发库强制执行风险迁移。

## 16. 批次、时间和证据

六批次：公司底座2—3天；公共组件/看板2—3天；分类内容4—5天；首页固定页面5—7天；导航站点3—4天；回归交付2—4天。总计约18—26工作日，为工程量估计，不含用户验收等待/外部服务等待/新增范围。

每步以真实截图、场景结果和数据对比交付，不能只报N/N测试通过；改前必须是真实记录。双客户正反修改验证，测试数据明确标识。新测试来源是用户30步验收条目，注明覆盖和未覆盖范围。详细30步见 EXECUTION.md，用户确认记录见 PROGRESS.md。
