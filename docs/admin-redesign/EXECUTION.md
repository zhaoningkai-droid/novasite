# 六批次、三十步执行与验收清单

依据 IMPLEMENTATION.md；每步约半天至一天有效工作量，复杂问题单列影响，不压缩验收。
执行规则：完成一步→提交证据→状态“待用户验收”→用户明确确认→下一步。批次末同时验收本批次。只授权第1步，不能连续做多步。修改结构前提交字段/风险/备份，危险迁移另等确认。截图、实际结果及相关功能回归每步必交，不能口头通过。
