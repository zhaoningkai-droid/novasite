## 禁止双重数据源

1. 产品推荐继续以内容管理的`featured + sortOrder`为依据，不再新建首页专属产品副本。
2. 产品分类名称、数量和筛选使用同一个product-categories及products.category关系。
3. 联系页、页脚、悬浮条读取同一份tenant.contact，缺字段显示空状态，不填参考站的电话。
4. 首屏/横幅图在首页Banner配置中维护；模板只决定裁切和位置，不在模板记录中复制图片正文。
5. FAQ与首页FAQ结构化数据只取真实FAQ记录；模板不保存另一组问题。
6. 切换模板只改变有限的布局选项及其版本，不重写客户内容、导航、URL、媒体或询盘。
