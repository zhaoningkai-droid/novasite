## 页面观察

### 575 · 家居展示型

- 首页呈现大幅圆角首屏与叠加导航；其后为图文介绍、案例、分类入口、产品、新闻和多列页脚。参考入口：[首页](http://zh.preview.default3.temp.o668.com/)、[产品列表](http://zh.preview.default3.temp.o668.com/product/)、[产品详情](http://zh.preview.default3.temp.o668.com/product/5.html)、[新闻列表](http://zh.preview.default3.temp.o668.com/article/)、[新闻详情](http://zh.preview.default3.temp.o668.com/article/41.html)、[案例列表](http://zh.preview.default3.temp.o668.com/case/)、[关于](http://zh.preview.default3.temp.o668.com/about/)、[FAQ](http://zh.preview.default3.temp.o668.com/faq/)、[联系](http://zh.preview.default3.temp.o668.com/contact/)。
- 产品列表含左侧类别及卡片分页。产品详情偏文章式，参数没有独立表格、详情图片区较少；后续新模板应补足产品型详情，同时不复制毛绒玩具演示文案。
- 产品分类页打开“动物形象类”后显示两款产品；分类树和分页与该页列表共存，未穷举其他分类。案例详情有面包屑、标题/日期、分段正文、上一篇/下一篇以及分类/最新文章侧栏。
- 新闻列表有分类、日期/作者、摘要和分页；详情可包含长正文、表格、小标题和案例，侧栏带分类及最新文章。案例列表使用带日期、作者及摘要的条目。关于页使用多段图文和“展开阅读全文”；FAQ是可展开问题组。
- 缺陷/污染风险：FAQ包含重复问题及“撒大大”占位；页脚保留“外贸站点预览专用(勿动)”；文章混入示例电话、邮箱和演示业绩。这些只记录为来源内容问题。

## 五套相同点与实施边界

- 预览站共同有产品、新闻、案例、关于、FAQ、联系入口，页面主题区块不同。导航标签相似不能说明页面排版相同。
- 预览站内容普遍是毛绒玩具及虚构/示例公司素材，与模板行业名不匹配。不得导入预览站文字、电话、邮箱、品牌Logo或媒体。
- 五个模板分别成为模板库记录；每家公司选一个模板作为当前展示。可以预览多个模板，但不得对同一站点同时应用多个模板。
- 现有四个模板的key、布局和客户当前选用关系保留。新模板用新增key和隔离布局实现；实现中如需接触共享文件，必须证明旧模板输出未变。
