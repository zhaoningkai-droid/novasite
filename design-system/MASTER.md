# 前台模板设计约定

## Colors

每套模板独立作用域。Atelier 主色 #303b30，表面 #f8f7f3，文字 #242820，错误 #b42318，成功 #287044。

## Typography

Arial / PingFang SC / Microsoft YaHei。12、15、18、22、28、36、48、56px，正文行高 1.8。

## Spacing

4px 基准，8、12、16、24、32、48、64、96px。

## Breakpoints

sm 480、md 760、lg 1100、xl 1440。手机单列，桌面多列。

## Components

按钮实色深绿、清晰焦点；卡片无阴影；输入框保留明确边界；标签细边框。
模块读取后台真实内容，不使用虚构数字、默认企业图片或营销文案。

## 运营后台

### 设计原则

让主要任务先出现，按用途把信息分组；页面、表单、表格和详情使用不同信息密度。用稳定的对齐和间距表达关系，不以大面积渐变、重阴影或装饰性动画制造层级。每页只保留一个主要标题和一个明确的首要操作。错误、成功、保存中、空结果、只读权限和未保存状态都要有清楚且持续可见的表达。

### 颜色与字体

后台使用 `--ws-*` 令牌，不把这些变量延伸到客户站模板：主色 `#315be8`、浅主色 `#edf2ff`、正文 `#18233b`、次级文字 `#637089`、描边 `#e2e7ef`、页面底 `#f4f6fa`、成功 `#187451`、危险 `#b42336`、警示 `#855713`。以白色表面承载表单和列表；主色只用于主要动作、当前项和键盘焦点。正文 14px，辅助文字 12–13px，区块标题 16–18px，页面标题 24–28px。使用系统中文字体，保证跨平台回退。

### 页面骨架与间距

桌面顶部导航 64px，左侧导航 232px，页面工作区随屏幕增长且最大宽度 1600px；窄屏左导航变为可关闭的抽屉，页面本身不得横向溢出。按 4px 基准使用 8、12、16、24、32px 常用间距，表单字段顶部对齐，字段名、必填、说明和错误紧邻控件。表单优先分成信息卡片，不为单个输入框重复创建巨型卡片。容器圆角以 8–12px 为主，阴影只用于浮层。

### 列表和表单交互

表格工具区将搜索、筛选、批量操作和分页放在连续的内容区域；选择项后再显示批量动作，表头全选正确表达部分选择。列宽以真实内容分配；长文做省略并提供只读详情。分页显示真实总数，上一页/下一页在边界时禁用，筛选或翻页时清理不再匹配的选择。破坏性动作说明对象并默认聚焦取消，错误时保留上下文和选择。表单提交期间阻止重复提交，失败后保留输入；媒体上传清楚区分“文件进入媒体库”和“内容保存生效”。

### 可访问性与动效

页面提供跳到主内容链接、语义化标题、可见焦点、表单标签和状态播报。菜单支持 Escape 和焦点返回；对话框可通过键盘完整关闭，切换语言使用 tab 语义与方向键。颜色不能单独表达状态。按钮状态变化约 150ms，弹层淡入约 180ms，避免长距离位移和循环装饰动画。尊重 `prefers-reduced-motion`，减少动态效果时取消过渡与页面入场动画。

### 实施边界

运营工作台样式作用于 `(workspace)` 页面和 `--ws-*` 组件。客户站主题继续在各自模板作用域内；修改运营管理界面不自动改变客户网站样式或内容。
