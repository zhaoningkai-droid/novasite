# GEO工作台布局基线

这份基线记录 GEO 页面与参考后台的布局对照结果。样式只作用于 GEO 工作区，不改变独立站管理页面。参考界面沿用 NovaSite 工作台外框：顶部模块切换、左侧 GEO 导航、右侧白色内容区；页面采用白底、浅灰分隔线和蓝色主操作。

## 桌面栅格

- 桌面视口按 1440 CSS px 核对；顶部栏高 60px，左侧导航宽 200px，页面标题栏最小高 70px。
- 内容区随视口伸展，普通表单卡片不设置额外的窄最大宽度；长表格在表格面板内部滚动，不能把整个页面撑出视口。
- 普通输入高度 40px，表单字段统一对齐标签和控件，段落之间用稳定的垂直间距区分。
- 主按钮只用于保存、创建、生成和提交等主要动作；次要操作使用描边或文本按钮。

## 页面排布

| 页面               | 布局规则                                                                                                                                                                        |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| GEO优化词          | 桌面两列卡片，卡片宽度随内容区平分；详情字段按品牌、比对标识、核心词、十个细分词、官网与Blog的顺序排列。                                                                        |
| 素材库             | 素材组导航与图片网格分区；桌面图片网格五列，上传入口直接选择电脑文件，图片数量不限。                                                                                            |
| 文章创作列表       | 搜索/类型筛选和创建入口同一行；列表保留参考站的任务、语言、方向、文章数量、状态、发布关联、更新时间和操作字段。宽表横向滚动限制在表格面板中，操作列固定在右侧，长名称单行截断。 |
| 文章创作编辑       | 顶部步骤条对应任务信息、关键词、素材、创作方式；创作记录入口留在编辑标题旁。表单按步骤自上而下排列，双栏问题编辑区等宽，素材与创作方向区域不强行挤入同一行。                    |
| 文章发布           | 计划名称、手动/自动模式、发布时间、站点目标、文章选择与富文本编辑依次排列；不显示 Facebook、LinkedIn 或海外媒体费用。正文编辑器桌面宽度约 900px。                               |
| 自动发布计划       | 日期起止并排；24个小时选项按六列平铺，不显示上午/下午/晚上/深夜分组。间隔天数控件宽 92px，单位与数字同行；提交区位于表单末尾，不覆盖表单内容。                                  |
| 发布计划、发布记录 | 筛选区与内容表格分层，字段保持单行；超出工作区时只滚动表格。关键行操作固定在最右侧。                                                                                            |
| GEO报表            | 指标与观测依据按两列排列，在窄视口降为单列；明确区分保存、发布、品牌提及、推荐与页面引用，不展示模型 token 数。                                                                 |

## 多客户与交互约束

GEO页面继续处于当前公司工作区路由下。改变宽表布局、筛选样式或创作页面样式不能改变查询的公司范围。上传入口仍直接选择本机图片并加入当前客户素材组；不创建额外媒体库入口。表单状态和浏览器视口变化不能自动提交任务、文章或发布计划。

## 本轮布局修正

- 文章创作任务宽表设为 1560px 最小宽度并限制在表格面板内横向滚动；滚动区域可键盘聚焦，标题和创作方向超长时截断，时间/操作区保持单行，操作列固定。
- 发布计划列表保持单行字段并在面板内滚动。
- 自动计划表单限制计划名称宽度，压紧间隔数字输入框，日期字段不拆行，并移除覆盖页面的固定提交栏。
- 发布记录表增加独立表格样式，避免和创作记录规则互相覆盖。

最后一次浏览器核对路径：`http://localhost:3100/workspace/example/geo/creation`。DOM视口为 1440×900 CSS px；表格横向滚动发生在列表容器内，文档本身宽度保持 1440px。
