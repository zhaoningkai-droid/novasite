# K607 / K712 模板

稳定标识：`plush-607-v1`、`plush-712-v1`。公共视觉资源分别位于 `public/sites/k607` 和 `public/sites/k712`。

- 演示 `/template-demo/{key}/zh` 使用独立示例内容，不读取客户资料。
- 客户站 `/s/{site}/{lang}` 读取现有 CMS，演示与客户站共用同一套模板组件。
- 选择与保存模板使用现有后台流程；不复制演示内容，不清空客户内容。
- 产品、文章、案例、关于、FAQ、联系等页面由现有内容模型适配；询盘沿用现有真实提交与必填配置。
- 轮播、滚动、波纹与菜单等行为由对应模板组件提供。
- 目录项注册与客户选择分开执行，不能为注册模板调用演示 seed。

更多接入说明见 `docs/TEMPLATE_CATALOG.md`。页面与编辑体验待用户验收。
